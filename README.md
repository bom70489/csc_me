# CSC Practice Solutions

A collection of Java solutions for CSC programming exercises.

## Project Structure

- `solutions/` — one Java source file per numbered question
- `README.md` — repository overview and run instructions

## Run a Solution

Compile a solution from the repository root, then run its class from the `solutions` folder:

```bash
javac solutions/Q1.java
java -cp solutions Q1
``

Replace `Q1` with the question number you want to run.
